# TsubasaTommy/homebrew-tap

```sh
brew install tsubasatommy/tap/optiman
optiman install
```

| Formula | Description |
|---|---|
| [optiman](https://tsubasatommy.github.io/optiman/) | Converts photo folders to JPEG XL without any quality loss, using no resources while idle |

`optiman` was called `optimize-image-folder` up to 0.2.0. `brew update && brew upgrade` switches an existing install to `optiman`; run `optiman install` once afterwards to take over the settings and the launchd agent.
